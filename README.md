week 1# cybersecurity-labsetup
Welcome to my repository for the cybersecurity Internship Week 1 assignment. This project documents the initial setup and configuration of a secure local testing lab.
**Lab Tasks & Implementation**
1.   virtualization Setup.
2.   Installed and configured Oracle VM Virtual Box.

4.   Network & System Validation.
5.   Configured network adapter settings (NAT/Bridged mode).
6.   verified host to guest connectivity and tested system configurations using terminal commands.
**Commands Executed**

    Network interface status verification (ifconfig/ip a).
